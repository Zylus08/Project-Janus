# Classical Search Economics & Computational Profiling (P1.16 Phase 8)

## Executive Summary

Phase 8 of Milestone P1.16 establishes an empirical computational profile of the Janus classical alpha-beta search pipeline, quantifying micro-architectural latencies, branching economics, and resolving historical claims from Milestone P1.15.

All benchmarks were captured directly via `analysis/phase1/p1.16/tests/profile_search_economics.py`, executing 100,000 iterations per component on dedicated execution hardware.

### Key Architectural Discovery: The Cost of Quiet Moves
Quiet move generation requires $2,607.9$ ns per call—**$2.20\times$ more expensive than capture generation** ($1,185.3$ ns).
This fundamental performance disparity explains why the selective checking experiments in Phase 5 (Q2 and Q3) severely deteriorated search throughput ($-27.8\%$ NPS drop): attempting to generate and probe quiet checking moves in quiescence forces the engine to run the heavy quiet move generator at leaf nodes, forfeiting the high-speed capture-only pruning that defines effective quiescence search.

## 3. Milestone P1.15 Game 12 Forensics: Dissecting the $18.7\times$ Node Reduction

In Milestone P1.15, Game 12 was cited as evidence of an "$18.7\times$ node reduction" achieved by candidate X19. Phase 8 subjected this exact tactical position (`r1bqkb1r/pppp1ppp/2n5/4p3/2B1n3/5Q2/PPPP1PPP/RNB1K1NR w KQkq - 0 5`) to isolated comparative profiling between legacy Q0 and corrected Q1:

| Architecture | Quiescence Mode | Search Depth | Total Nodes | Principal Score | Node Ratio |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **Legacy Janus (P1.15 X19)** | Q0 (Legacy Blind) | 8 | 420,646 | $+28999$ | Baseline ($1.00\times$) |
| **Corrected Janus (P1.16 X21)** | **Q1 (Corrected)** | **8** | **12,376** | **$+28999$** | **$33.99\times$ Reduction** |

### Scientific Verdict on Game 12:
1. **The Phenomenon Was Real, But Misunderstood:** In tactical positions with forced checkmate threats, legacy Q0 was completely blind to mate in quiescence (evaluating checkmate positions as modest $-89$ cp deficits). Because Q0 could not recognize checkmate at leaf nodes, the negamax search was forced to wander through extensive spurious capture variations, exploding the tree to **420,646 nodes**.
2. **The True Mechanism of Reduction:** Corrected Q1 immediately detects checkmate at quiescence leaf nodes (`return -(MATE_SCORE - ply)`), triggering immediate, decisive alpha-beta cutoffs across all alternative branches. As a result, the search solves the position completely in just **12,376 nodes**—a **$34.0\times$ reduction** in search effort.
3. **Conclusion:** Tactical quiescence correctness is an immense computational accelerator, eliminating hundreds of thousands of useless search nodes generated by quiescence blindness.
