## 2. P1.17 Scientific Reconciliation & Tournament Harness Certification

### 2.1 Full Audit of Reported P1.16 Stockfish Wins
During P1.16, an anomalous win rate of 22.5–27.5% was claimed against Stockfish 4, 11, and 19. A microscopic inspection of the raw PGN transcripts revealed that `run_p116_tournaments.py` evaluated game termination via:
```python
# The defective P1.16 code:
if score is not None and score > 1000 and len(moves_history) >= 40:
    termination = "white_win" # INVERSION BUG!
```
When Black was searching and reported a winning score from its side-to-move perspective (`score > 1000`, e.g. $+1500$ cp for Black), the script incorrectly awarded the victory to **White**. All 29 claimed Stockfish wins were direct manifestations of this flaw.

### 2.2 Historical Contamination Audit
An automated audit of all 65 historical tournament scripts from Milestone P1.0 through P1.17 confirmed that:
- P1.0 through P1.15 scripts were completely free of the inversion defect.
- The defect was introduced solely in `run_p116_tournaments.py`.
- P1.17 correctly identified the anomaly and re-ran tournaments under a preliminary patch.

## 4. Targeted C++17 Evaluation Implementation (Candidate X23)

### 4.1 Track A: Classical Backward Pawn Detection
Implemented in `engine/classical_x/janus_classical_x.cpp` inside `eval_pawn_structure`:
```cpp
if (g_use_backward_pawns) {
    int base_sq = (c == WHITE) ? bitscan_forward(f_pawns) : bitscan_reverse(f_pawns);
    int base_r = base_sq / 8;
    int stop_sq = (c == WHITE) ? (base_sq + 8) : (base_sq - 8);
    if (stop_sq >= 0 && stop_sq < 64) {
        uint64_t stop_attackers = pawn_attacks[c][stop_sq];
        if (stop_attackers & enemy_pawns) {
            uint64_t friendly_adj = my_pawns & adjacent_files_mask(f);
            bool has_supporter_behind = false;
            while (friendly_adj) {
                int asq = bitscan_forward(friendly_adj);
                friendly_adj &= friendly_adj - 1;
                int ar = asq / 8;
                if ((c == WHITE && ar <= base_r) || (c == BLACK && ar >= base_r)) {
                    has_supporter_behind = true;
                    break;
                }
            }
            if (!has_supporter_behind) {
                mg[c] -= 10;
                eg[c] -= 15;
            }
        }
    }
}
```

### 4.2 Track B: Open & Semi-Open File King Exposure
Implemented inside `eval_king_safety`:
```cpp
if (g_use_king_file_exposure) {
    uint64_t en_heavy = b->pieces[them][ROOK] | b->pieces[them][QUEEN];
    int exposure_penalty = 0;
    uint64_t my_kf_pawns = b->pieces[c][PAWN] & FILE_MASKS[kf];
    uint64_t en_kf_pawns = b->pieces[them][PAWN] & FILE_MASKS[kf];
    bool has_en_heavy_kf = (en_heavy & FILE_MASKS[kf]) != 0;
    if (!my_kf_pawns && !en_kf_pawns) {
        exposure_penalty += has_en_heavy_kf ? 40 : 25;
    } else if (!my_kf_pawns && en_kf_pawns) {
        exposure_penalty += has_en_heavy_kf ? 25 : 15;
    }
    for (int adj_f : { kf - 1, kf + 1 }) {
        if (adj_f >= 0 && adj_f <= 7) {
            uint64_t my_adj_pawns = b->pieces[c][PAWN] & FILE_MASKS[adj_f];
            bool has_en_heavy_adj = (en_heavy & FILE_MASKS[adj_f]) != 0;
            if (!my_adj_pawns) {
                exposure_penalty += has_en_heavy_adj ? 14 : 8;
            }
        }
    }
    mg[c] -= std::min(80, exposure_penalty);
}
```

1. **Isolate Track A into Candidate X24:** Preserve Backward Pawn detection ($-10$ mg / $-15$ eg), 64K pawn hashing, True Outposts, and Q1 corrected quiescence search. Remove Track B (king file exposure) entirely to eliminate the $-88.7$ Elo penalty.
