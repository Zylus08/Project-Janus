## 2. Milestone P1.19 Scientific Reconciliation

### 2.1 The P1.19 Match 4 Anomaly
Milestone P1.19 Match 4 reported that Candidate X24 collapsed to 37.0% (-92.5 Elo) against Baseline X7 at $3.0\text{s}+100\text{ms}$.
Phase 0 independently audited the 50 games from `analysis/phase1/p1.19/pgn/p119_match_4_x24-s_vs_x7_slow.pgn`.
- Reconstructed record: $+9 =19 -22$ across 25 opening pairs (18.5 / 50 points, 37.0%).
- Pentanomial distribution: $[1, 2, 8, 9, 5]$.
- Standard error: $SE = 0.0523$.
- Two-sided Student's $t$-statistic:
  $$t = \frac{0.370 - 0.500}{0.0523} = -2.4856 \implies p = 0.0129$$
Since $p < 0.05$ and the 95% confidence interval $[26.75\%, 47.25\%]$ has an upper bound strictly below 50.0%, the regression was statistically indisputable.

## 4. Root Cause Forensics: Search–Evaluation Incompatibility

### 4.1 Reverse Futility Pruning (RFP) Suppression
Reverse Futility Pruning prunes a non-PV node at shallow depths ($d \le 3$) when the static evaluation exceeds $\beta$ by a safety margin:
$$\text{StaticEval} - \text{margin}(d) \ge \beta$$
When backward-pawn penalties ($-10\text{ mg} / -15\text{ eg}$) were active, the static evaluation of slightly advantageous positions was artificially lowered by $15\text{–}30\text{ cp}$. This prevented RFP from triggering on quiet branches, forcing the alpha-beta search to explore subtrees that would otherwise have been cut off.
- Across 30 diagnostic positions (Phase 5), backward pawns increased search tree nodes by an average of **$+27.3\%$**.
- In complex pawn endgames, node counts exploded by up to $300\%$, consuming search budget that was urgently needed for tactical calculation.

### 4.2 Passive Piece Defense in Deep Search
Counterfactual replays of Match 4 losses (Phase 4) revealed that at depths 8–10 (reached only at 3.0s), the search tree was deep enough to see backward pawns being attacked, but not deep enough to see counter-attacks. Consequently:
- Candidate X24 repeatedly favored passive defensive moves (e.g., `Bf8` guarding d6, `Qc4` guarding c7) over active tactical breakthroughs (e.g., `Be3`, `Qf7`).
- The passive pieces became tied down to defending static weaknesses, allowing Baseline X7 to mobilize its rooks and kings for decisive wins.

## 5. Architectural Intervention: Option B (Connected Passed Pawns)

### 5.1 Formulation & Implementation
To replace regressive static penalties with active dynamic positional knowledge, Phase 7 selected **Option B: Connected and Supported Passed Pawns**:
- A passed pawn is **connected** if a friendly passed pawn exists on an adjacent file and within $\pm 1$ rank. Bonus: $+30\text{ mg} / +50\text{ eg}$.
- A passed pawn is **supported** if a friendly non-passed pawn defends it or sits on an adjacent file on the rank directly behind. Bonus: $+20\text{ mg} / +35\text{ eg}$.
- **Pawn-Hash Caching:** Calculated strictly inside `evaluate_pawn_structure()` and cached directly in the 64K pawn transposition table, incurring **$0.0\%$ NPS search penalty**.

### 5.2 Development Ablation Results (Phase 9)
- `DEV_1_FAST` (B1 vs B0 @ 1.0s+50ms): **28.0 / 50 (56.0%, +41.9 Elo, $p = 0.0445$)** $\to$ statistically significant gain.
- `DEV_2_SLOW` (B1 vs B0 @ 3.0s+100ms): **27.0 / 50 (54.0%, +27.9 Elo, $p = 0.2449$)** $\to$ stable performance across time controls.
- `DEV_3_BP` (B1 vs B2): 23.0 / 50 (46.0%, -27.9 Elo) $\to$ confirming that backward pawns hurt Option B when combined.
