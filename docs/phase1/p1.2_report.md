## 3. Continuation History Architecture (Phase 1)

Standard history heuristics track quiet move cutoff frequency globally on a $2 \times 64 \times 64$ table. Continuation history conditions cutoff probabilities on preceding plies.

### Architecture Formulation
In `engine/classical_x/janus_classical_x.cpp`:
- `g_conthist_1ply[6][64][6][64]`: Indexed by `[prev_piece][prev_to][curr_piece][curr_to]`.
- `g_conthist_2ply[6][64][6][64]`: Indexed by `[prev2_piece][prev2_to][curr_piece][curr_to]`.
- Memory Footprint: $2 \times 288\text{ KB} = 576\text{ KB}$ (int16_t).
- Gravity Update: $cur \leftarrow cur + bonus - (cur \times |bonus| / 16384)$, where $bonus = \min(300, d^2)$.

## 4. Dynamic Late Move Reduction (Phase 2)

### Architecture Formulation
Replaces fixed $R=1$ with a dynamic logarithmic table and history-conditioned adjustments:
$$R_{\text{base}}(d, m) = \left\lfloor 0.75 + \frac{\ln(d) \cdot \ln(m)}{2.25} \right\rfloor$$
- If combined history > 10,000 cp: $R \leftarrow R - 1$.
- If combined history < -5,000 cp: $R \leftarrow R + 1$.
- Strict safety invariants prevent reduction on checks, captures, promotions, and killer moves.
