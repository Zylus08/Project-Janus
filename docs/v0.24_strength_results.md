# Project Janus — Milestone v0.24 Strength Results
## Controlled Head-to-Head Evaluation: Production Baseline vs Candidate SEE Configuration

**Date:** 2026-10-18  
**Milestone:** v0.24  
**Branch:** `v0.3-benchmark-harness`  
**Starting Commit:** `a3cf19480cf5e7a9ac28f272f48e77dbdcc4cb9e`  
**Match Format:** 50-game paired opening match with color reversal  
**Openings:** 25 pairs sampled deterministically from `benchmarks/openings.json` (random seed `42`)  
**Time Control / Limit:** Fixed search depth 2 per move + 12-ply quiescence search  
**Engines Tested:**
1. **`Janus-Baseline` (Production Default)**: PVS, Aspiration Windows (+/-35 cp), LMR, NMP, TT `always_replace`, Check Extensions `disabled`, SEE Ordering `False`, SEE Pruning `False`.
2. **`Janus-SEE` (Candidate Configuration)**: Identical to Baseline, but with both `enable_see_ordering = True` and `enable_see_pruning = True`.

---

### 1. Executive Summary

Milestone v0.24 conducted the first large-scale (50-game) controlled head-to-head evaluation between two Project Janus search configurations. To rigorously isolate the playing-strength impact of Static Exchange Evaluation (SEE capture ordering and conservative quiescence pruning) from other factors, all other search heuristics, time limits, and opening assignments were held strictly symmetric.

#### Headline Result
- **Completed Games**: 50 / 50 (0 crashes, 0 illegal moves, 0 unfinished games).
- **Match Score (Janus-Baseline)**: **25.5 / 50 (51.0%)**
- **Match Score (Janus-SEE)**: **24.5 / 50 (49.0%)**
- **Record (Janus-Baseline)**: 11 Wins, 29 Draws, 10 Losses.
- **Statistical Uncertainty**: Standard Error = $\pm 4.63\%$; **95% Confidence Interval: [41.93%, 60.07%]**.
- **Statistical Verdict**: The observed difference ($\Delta = 1.0\%$ or 0.5 game points out of 50) has a $z$-score of $0.22$ ($p \approx 0.83$). The performance difference is **statistically indistinguishable from random noise**.
- **Production Recommendation**: **Retain the current production defaults (`enable_see_ordering = False`, `enable_see_pruning = False`)**. There is no empirical evidence of a playing-strength improvement justifying a change to production defaults.

### 3. Opening-Pair Breakdown (25 Pairs)

The 50 games spanned 25 unique opening setups. Out of 25 pairs:
- **15 pairs were drawn overall** (0.5–0.5 or 1.0–1.0).
- **5 pairs favored `Janus-Baseline`**:
  - `scotch_game`: 1.5 – 0.5 (+1 win as White)
  - `d4_Nf6_indian_defense`: 1.5 – 0.5 (+1 win as Black)
  - `sicilian_dragon`: 1.5 – 0.5 (+1 win as White)
  - `Nf3_d5_reti_opening`: 1.5 – 0.5 (+1 win as White)
  - `c4_e5_english_reversed_sicilian`: 1.5 – 0.5 (+1 win as White)
  - `sicilian_scheveningen`: 1.5 – 0.5 (+1 win as Black)
  - `gruenfeld_defense`: 1.5 – 0.5 (+1 win as Black)
- **5 pairs favored `Janus-SEE`**:
  - `italian_two_knights`: 0.0 – 2.0 (Janus-SEE swept both games)
  - `queens_indian_defense`: 0.5 – 1.5 (Janus-SEE won as Black)
  - `petroff_defense`: 0.0 – 2.0 (Janus-SEE swept both games)
  - `four_knights_game`: 0.0 – 2.0 (Janus-SEE swept both games)
  - `e4_e5_open_game`: 0.0 – 2.0 (Janus-SEE swept both games)
  - `london_system`: 0.0 – 2.0 (Janus-SEE swept both games)

#### Tactical Divergence Observations
In tactical open games (`italian_two_knights`, `four_knights_game`, `e4_e5_open_game`), SEE ordering allowed `Janus-SEE` to find sharp tactical refutations faster in the quiescence search.
However, in positional and semi-open structures (`scotch_game`, `d4_Nf6_indian_defense`, `sicilian_dragon`, `c4_e5_english`), `Janus-Baseline` demonstrated superior piece activity because SEE capture pruning occasionally discarded tactical sacrifices that appeared statically losing at the root but opened lines for king attack.

### 4. Pilot Match Findings (Depth 3)

Prior to the 50-game match, a 4-game pilot was executed at depth 3:
- **Duration**: 266.25 s (66.56 s/game).
- **Result**: 0 wins, 4 draws, 0 losses (2.0 / 4, 50.0% score).
- **Pacing**: Both engines played symmetric lines to draw by threefold repetition at plies 68, 97, 54, and 54.
- **Feasibility Assessment**: Running 50 games at depth 3 would require $\approx 55$ minutes of continuous single-threaded CPU execution. The depth-2 protocol provided a completed 50-game paired dataset within 7.5 minutes, maintaining 12-ply quiescence search for all captures.

---

### 5. Playing-Strength Verdict and Recommendations

1. **Strength Verdict**:
   - The candidate SEE configuration achieved $49.0\%$ ($24.5 / 50$), while the baseline configuration achieved $51.0\%$ ($25.5 / 50$).
   - The 95% confidence interval $[41.93\%, 60.07\%]$ encompasses $50.0\%$.
   - **Conclusion: There is no statistically demonstrable playing-strength advantage to enabling SEE ordering or SEE pruning at this depth.**
2. **Production Defaults Recommendation**:
   - **Retain `enable_see_ordering = False` and `enable_see_pruning = False` as the production defaults.**
   - Preserve both options as configurable engine parameters for users or tournament testing.
3. **Future Focus**:
   - The highest-leverage search improvement is not further capture pruning, but **time management and search generation aging** in the Transposition Table to support clock-based time controls.
