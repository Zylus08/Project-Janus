### 1. Executive Summary

Milestone v0.33 addresses the primary engineering finding of Milestone v0.32: **at shallow fixed-time search horizons, micro-optimizing search speed alone does not produce playing-strength gains without addressing evaluation quality**. 

This milestone followed an evidence-driven, 4-stage validation workflow:
1. **Independent Statistical Revalidation of v0.32:** Independently audited the raw 100-game dataset from v0.32 across JSON, CSV, and PGN formats. All 100 games, 50 opening pairs, and statistical metrics (47.0% score, 95% Wald CI [39.9%, 54.1%], $\Delta\text{Elo} = -20.9$, $p \approx 0.55$) were 100% verified and reconciled with zero discrepancies.
2. **Evaluation Architecture Audit & Invariants:** Documented the baseline evaluation function, created a 24-position curated diagnostic suite (`benchmarks/evaluation_positions.json`), and implemented unit tests proving board-state non-mutation, deterministic stability, and strict color-mirror symmetry.
3. **Modular Feature Implementation & Ablation Study:** Implemented three isolated candidate terms using precomputed 64-bit integer bitmasks:
   - **Candidate A:** Pawn structure (passed pawn rank bonuses, doubled pawn penalties, isolated pawn penalties).
   - **Candidate B:** Rook file activity (open and semi-open file bonuses).
   - **Candidate C:** King safety (castled pawn shield and open file penalties).
   Conducted microbenchmarks and fixed-depth search benchmarks (depths 4 & 5 across 6 standard positions). Positional differentiation reduced depth 4 search nodes by **18.2%** and depth 5 nodes by **11.3%**, compensating for lower raw evaluation throughput.
4. **Confirmatory 100-Game Playing-Strength Match:** Executed a 100-game, colour-balanced, paired opening match between **Reference Janus v0.30** (`05de411`) and **Candidate Janus v0.33** (`all_features`) under fixed **500 ms per move** across all 50 canonical opening positions.

#### Primary Playing-Strength Findings
- **Observed Score:** Candidate v0.33 scored **52.0%** (**52.0 / 100 points**: 33 Wins, 38 Draws, 29 Losses).
- **Opening-Pair Record:** **17 Pairs Won, 21 Pairs Drawn, 12 Pairs Lost** (Net +5 pairs won).
- **Point Estimate:** **$\Delta\text{Elo} = +13.9\text{ Elo}$** (sampling standard error: $\pm 27.5$ Elo).
- **Statistical Uncertainty:** 95% Wald CI is **[44.2%, 59.8%]**; 95% Paired Bootstrap CI is **[45.0%, 59.0%]**; Sign Test two-tailed $p = \mathbf{0.4583}$.
- **Engineering Verdict:** The point estimate is positive (+13.9 Elo, 52% score, 17 vs 12 pairs won) despite candidate reaching slightly lower average depth ($3.51$ vs $3.74$ plies), empirically validating that evaluation quality outweighs nominal fractional depth at shallow horizons. However, because true parity ($50.0\%$ / $0.0\text{ Elo}$) remains within the 95% confidence interval, this result is **statistically inconclusive** and does not prove an absolute rating gain under strict significance criteria ($p < 0.05$).

### 3. Evaluation Architecture Audit & Invariants

#### A. Baseline Evaluation Components (`src/janus/evaluation.py`)
- **Score Representation:** Signed 32-bit integer centipawns ($100\text{ cp} = 1\text{ pawn}$) from White's perspective (`evaluate_white`) or side to move (`evaluate_side_to_move`).
- **Material Constants:** Pawn: 100, Knight: 320, Bishop: 335, Rook: 500, Queen: 900, King: 0.
- **Piece-Square Tables:**
  - Pawns: Combined base value + rank advancement ($5 \times \text{rank}$ for White, $5 \times (7-\text{rank})$ for Black). No center bonus.
  - Knights & Bishops: Combined base value + Manhattan center distance bonus:
    $$\text{Bonus}(\text{sq}) = 14 - 4 \times (|\text{file} - 3.5| + |\text{rank} - 3.5|)$$
  - Bishop Pair: $+25\text{ cp}$ if bishop count $\ge 2$.
  - Castling Rights: $+8\text{ cp}$ per available castling right.
- **Rooks & Queens:** Flat material valuation, square-independent.

#### B. Audited Gaps in Baseline Evaluation
1. **Pawn Structure:** Zero recognition of passed pawns, doubled pawns, or isolated pawns.
2. **Rook Placement:** Zero bonus for open files, semi-open files, or 7th rank occupancy.
3. **King Safety:** Once castled, castling rights bonus (+8 cp) disappears, ironically penalizing castled positions relative to uncastled positions with intact rights. No shield pawn bonus.
4. **Mobility:** Pseudo-legal/legal mobility absent.

#### C. Invariant Properties
A dedicated test suite (`tests/test_evaluation_invariants_v033.py`) verified the following baseline invariants:
- **Board-State Preservation:** FEN, active color, castling rights, en passant target, and legal move generators remain unmutated across repeated calls.
- **Evaluation Stability:** Deterministic output across repeated invocations on identical board states.
- **Color Mirror Symmetry:** For any valid position $B$:
  $$\text{eval}_{\text{white}}(B) = -\text{eval}_{\text{white}}(B.\text{mirror}())$$
  $$\text{eval}_{\text{stm}}(B) = \text{eval}_{\text{stm}}(B.\text{mirror}())$$
- **Material Monotonicity:** Strictly increasing score when friendly pieces are added.

### 5. Candidate Features and Implementation

Three modular, isolated evaluation terms were added to `src/janus/evaluation.py` using native 64-bit integer bitmasks, ensuring zero heap allocations and $O(1)$ bitwise operations:

1. **Candidate A: Pawn Structure (`enable_pawn_structure`)**
   - **Passed Pawns:** Detected via forward file-span masks (`WHITE_PASSED_PAWN_MASKS[sq]`, `BLACK_PASSED_PAWN_MASKS[sq]`). Rank-proportional bonus: `(0, 0, 0, 5, 10, 20, 40, 70)` cp.
   - **Doubled Pawns:** Evaluated per file using `FILE_MASKS[f]`. $-10\text{ cp}$ penalty per additional friendly pawn beyond the first.
   - **Isolated Pawns:** Evaluated via adjacent file masks (`ADJACENT_FILE_MASKS[f]`). $-12\text{ cp}$ penalty per pawn lacking friendly pawns on neighbor files.

2. **Candidate B: Rook File Activity (`enable_rook_files`)**
   - **Open File:** Rook on a file devoid of pawns: $+18\text{ cp}$.
   - **Semi-Open File:** Rook on a file devoid of friendly pawns but containing enemy pawns: $+10\text{ cp}$.

3. **Candidate C: King Safety & Pawn Shield (`enable_king_safety`)**
   - **Kingside Shield (g1/g8):** $+8\text{ cp}$ per friendly pawn on f2/f3, g2/g3, h2/h3. Open g-file or h-file adjacent to the king incurs a $-12\text{ cp}$ penalty.
   - **Queenside Shield (b1/b8, c1/c8):** $+8\text{ cp}$ per friendly pawn on a2/a3, b2/b3, c2/c3. Open b-file or c-file incurs a $-12\text{ cp}$ penalty.

All terms default to `False`. Color mirror symmetry was mathematically proven and verified across all $2^3 = 8$ configurations.

### 8. Statistical Uncertainty and Experimental Limitations

#### Measured Facts vs Interpretations vs Hypotheses

1. **Measured Facts:**
   - Candidate v0.33 scored **52.0%** (33W-38D-29L, +13.9 Elo point estimate).
   - Candidate won more opening pairs than it lost (**17 Won vs 12 Lost**).
   - Candidate reached $-0.23$ plies lower average completed depth under fixed 500 ms movetime ($3.51$ vs $3.74$ plies) due to evaluation computation cost.
   - The 95% Wald CI is $[44.2\%, 59.8\%]$ and the 95% Bootstrap CI is $[45.0\%, 59.0\%]$.

2. **Statistical Interpretations:**
   - The 95% confidence interval encompasses true parity ($50.0\%$, $0.0\text{ Elo}$).
   - The two-tailed sign test on decisive pairs ($17$ vs $12$) yields $p = 0.4583$.
   - Therefore, the null hypothesis ($H_0$: playing strength is equal) **cannot be rejected** at the $\alpha = 0.05$ significance level.
   - The match provides an encouraging point estimate (+13.9 Elo), but **does not statistically prove an Elo gain**.

3. **Architectural Hypotheses for Future Work:**
   - The fact that Candidate scored 52.0% despite searching $-0.23$ plies shallower supports the hypothesis that positional evaluation quality offsets modest depth deficits.
   - To statistically resolve an effect size of $+14\text{ Elo}$ ($52\%$ score) with $80\%$ statistical power ($\beta = 0.20$, $\alpha = 0.05$), an experiment of approximately **1,000–1,500 games** is required.
