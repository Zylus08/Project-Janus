Milestone **v0.34.3** executes an independent mathematical and statistical audit of the clean 100-game match dataset generated in v0.34.2. Rather than relying on previous aggregate summaries, this audit reconstructed every metric from raw per-game records, verified cryptographic digests, reconciled all hypothesis tests and confidence intervals, and resolved discrepancies between analytical and paired methods.

### Key Conclusions:
1. **Raw Dataset Integrity:** The authoritative dataset contains exactly 100 valid games and 50 complete colour-reversed opening pairs with **zero** infrastructure failures, crashes, timeouts, or retries. Every move was verified strictly legal.
2. **Reconstructed Match Outcome:** Janus v0.34 achieved **38 wins, 43 draws, and 19 losses**, scoring **59.5% (59.5 / 100)**. Point estimate Elo difference is **+66.8 Elo**.
3. **Paired t-Test Reconciliation ($t=2.780$):**
   - The reported t-statistic $t = 2.780$ was verified exactly on pair score differentials ($d_i = \text{Score}_i - 1.0$).
   - The previously reported p-value of $0.0054$ was mathematically reconciled: the prior script evaluated $t=2.780$ using a **normal $Z$ approximation** (`math.erfc`). The exact Student's $t$-distribution with $\text{df}=49$ yields **$p = 0.0077$**. Both values confirm statistical significance at $\alpha = 0.01$.
4. **Resolution of Confidence Interval Differences:**
   - The reported analytical interval `[-2.5, +136.2]` assumed $N=100$ independent Bernoulli trials ($\text{SE} = 0.0491$). This naive model ignores the variance reduction inherent in colour-reversed pairs.
   - When the paired experimental design is properly modeled ($\text{Var}(s) = 0.2336, \text{SE} = 0.0342$), the parametric paired delta-method interval is **`[+18.5, +115.1]`**, which closely matches the 10,000-resample paired bootstrap interval of **`[+20.9, +115.2]`**. Both pair-aware intervals strictly exclude zero.
5. **Sign Test ($p=0.0502$) vs Wilcoxon Test ($p=0.0045$):**
   - The paired sign test on 32 decisive pairs ($22\text{W} / 10\text{L}$) yields $p = 0.0502$, which is marginal relative to $\alpha = 0.05$. The sign test discards pair sweep magnitude and 18 tied pairs.
   - The Wilcoxon signed-rank test accounts for the fact that Candidate scored 7 clean sweeps (+1.0) and 0 sweep losses (-1.0), yielding $Z = -2.840, p = 0.0045$ ($p < 0.01$).
6. **Final Strength Verdict:** **SUPPORTED**. The statistical evidence confirms a genuine playing strength advantage under 500 ms movetime.

## 3. In-Depth Reconciliation of Discrepancies

### 3.1 Paired t-Statistic and p-Value Discrepancy ($p = 0.0054$ vs $p = 0.0077$)
In `scripts/audit_v0342_clean_match.py`, the paired t-test was implemented as:
```python
pair_diffs = [s - 1.0 for s in pair_scores]
mean_diff = sum(pair_diffs) / len(pair_diffs)  # +0.190
var_diff = sum((d - mean_diff) ** 2 for d in pair_diffs) / (len(pair_diffs) - 1)  # 0.23357
se_diff = math.sqrt(var_diff / len(pair_diffs))  # 0.06835
t_stat = mean_diff / se_diff  # 2.7799...
z = abs(t_stat)
t_test_p = 2.0 * (1.0 - 0.5 * (1.0 + math.erf(z / math.sqrt(2.0))))  # Normal Z approximation
```
The reported value of $0.0054$ was derived using the **standard normal (Gaussian) distribution** via `math.erf`. For $N=50$ pairs, the exact sampling distribution under the null hypothesis is Student's $t$-distribution with $\text{df} = 50 - 1 = 49$.

Integrating the exact Student's $t$ probability density function:
$$f(t; 49) = \frac{\Gamma(25)}{\sqrt{49\pi}\Gamma(24.5)}\left(1 + \frac{t^2}{49}\right)^{-25}$$
yields:
$$p = 2 \int_{2.7799}^\infty f(u; 49) du = \mathbf{0.007684} \approx \mathbf{0.0077}$$
Because Student's $t$-distribution has heavier tails than the normal distribution, the exact $p$-value is $0.0077$ rather than $0.0054$. **Both values are $< 0.01$, so this technical discrepancy does not alter the conclusion: the difference is statistically significant.**

### 3.2 Analytical Elo CI (`[-2.5, +136.2]`) vs Paired Bootstrap CI (`[+20.9, +115.2]`)
Why did the analytical interval include zero while the bootstrap interval strictly excluded zero?
- **The Naive Analytical Model:** Assumed all 100 games were independent identically distributed (i.i.d.) Bernoulli trials. The variance of the score proportion was calculated as $\text{Var}(p) = \frac{p(1-p)}{100} = \frac{0.595 \times 0.405}{100} = 0.002410$, giving $\text{SE}(p) = 0.04909$ and $\text{SE}(\text{Elo}) = 35.39$. This yielded:
  $$\text{Elo CI}_{\text{naive}} = 66.8 \pm 1.96 \times 35.39 = \mathbf{[-2.5, +136.2]}$$
- **The Paired Reality:** The match used 50 colour-reversed pairs. Within each pair, the candidate played both White and Black from the identical opening FEN. This cancels out opening advantage and colour bias.
  Empirical pair score variance is $\text{Var}(s) = 0.23357$.
  The standard error of the mean score under the paired design is:
  $$\text{SE}(p)_{\text{paired}} = \frac{\sqrt{\text{Var}(s)/50}}{2} = \mathbf{0.03417}$$
  Pairing reduced the standard error from $0.04909$ to $0.03417$ (a **30.4% variance reduction**).
  Applying the delta method with the paired standard error gives:
  $$\text{Elo CI}_{\text{paired}} = 66.8 \pm 1.96 \times 24.65 = \mathbf{[+18.5, +115.1]}$$
- **Alignment with Bootstrap:** The paired delta-method interval (`[+18.5, +115.1]`) aligns closely with the paired bootstrap interval (`[+20.9, +115.2]`). Both pair-aware methods strictly exclude zero. The naive analytical interval overlapped zero solely because it mischaracterized the experimental design as 100 independent games.

### 3.3 Sign Test ($p=0.0502$) vs Paired t-Test ($p=0.0077$)
The paired sign test evaluates $H_0: P(\text{Pair Win}) = P(\text{Pair Loss})$ on decisive pairs.
- Number of decisive pairs: $N_{\text{decisive}} = 22 + 10 = 32$.
- Candidate wins: 22; Candidate losses: 10.
- Exact two-tailed binomial $p$-value:
  $$p = 2 \times \sum_{i=0}^{10} \binom{32}{i} 0.5^{32} = \mathbf{0.050153} \approx \mathbf{0.0502}$$
Because $0.0502 > 0.05$, the sign test is marginally above the conventional $0.05$ significance threshold.
Why is the sign test less significant than the paired t-test ($p=0.0077$) and Wilcoxon test ($p=0.0045$)?
1. **Discarding Ties:** The sign test completely drops the 18 tied pairs, reducing effective sample size from 50 to 32.
2. **Discarding Magnitude:** The sign test treats a 2.0–0.0 sweep identically to a 1.5–0.5 win. In the clean match:
   - Candidate had **7 clean sweeps (+1.0)** and **15 narrow wins (+0.5)**.
   - Reference had **0 clean sweeps (-1.0)** and **10 narrow wins (-0.5)**.
   Candidate was never swept in any pair. By incorporating magnitude, the Wilcoxon test ($p=0.0045$) and paired t-test ($p=0.0077$) capture this asymmetry, whereas the sign test discards it.
