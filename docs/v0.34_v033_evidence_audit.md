### 3. Recomputed Statistical Estimates

Using both game-level and paired-cluster formulations:

#### A. Game-Level Point Estimates & Uncertainty
- **Candidate Score:** $S = \frac{52.0}{100} = 0.520$ ($52.0\%$).
- **Game Sample Variance:**
  $$s^2 = \frac{1}{99} \left[ 33(1.0 - 0.52)^2 + 38(0.5 - 0.52)^2 + 29(0.0 - 0.52)^2 \right] = 0.15616$$
- **Game Standard Error:** $SE_{\text{game}} = \sqrt{0.15616 / 100} = 0.03952$ ($3.95\%$).
- **95% Wald Confidence Interval:**
  $$[0.52 - 1.96(0.03952), 0.52 + 1.96(0.03952)] = [44.25\%, 59.75\%]$$

#### B. Conventional Elo-Equivalent Conversion
- **Point Estimate:**
  $$\Delta E = -400 \log_{10}\left(\frac{1}{S} - 1\right) = -400 \log_{10}\left(\frac{1}{0.52} - 1\right) = \mathbf{+13.90\text{ Elo}}$$
- **Delta Method Standard Error:**
  $$\frac{d(\Delta E)}{dS} = \frac{400}{\ln(10) \cdot S(1-S)} = \frac{400}{2.302585 \cdot (0.52 \cdot 0.48)} = 695.98\text{ Elo / score unit}$$
  $$SE(\Delta E) = 695.98 \times 0.03952 = \pm 27.50\text{ Elo}$$
- **95% Elo Confidence Interval:**
  $$[13.90 - 1.96(27.50), 13.90 + 1.96(27.50)] = \mathbf{[-40.0\text{ Elo}, +67.8\text{ Elo}]}$$

#### C. Paired-Opening Cluster Analysis
Because games within the same opening pair share an identical starting position, observations within a pair are not independent. Treating the opening pair as the unit of observation ($M = 50$ pairs):
- **Pair Score Fraction:** $z_j = \frac{y_j}{2.0} \in \{0.0, 0.25, 0.50, 0.75, 1.00\}$.
- **Mean Pair Fraction:** $\bar{z} = 0.520$.
- **Paired Sample Variance:** $s_{\text{pair}}^2 = \frac{1}{49} \sum_{j=1}^{50} (z_j - 0.52)^2 = 0.06337$.
- **Paired Standard Error:** $SE_{\text{pair}} = \sqrt{0.06337 / 50} = 0.03560$ ($3.56\%$).
- **Paired t-Statistic:** $t = \frac{0.52 - 0.50}{0.03560} = \mathbf{0.5618}$ ($df = 49$, two-tailed $p = \mathbf{0.5743}$).
- **Pair Bootstrap 95% Confidence Interval:**
  - 2,000 resamples (seed 42): **[45.0%, 59.0%]**
  - 100,000 resamples: **[45.0%, 59.0%]**

#### D. Decisive Pairs Non-Parametric Sign Test
- **Pairs Won by Candidate ($y_j > 1.0$):** 17 (34.0%)
- **Pairs Drawn ($y_j == 1.0$):** 21 (42.0%)
- **Pairs Lost by Candidate ($y_j < 1.0$):** 12 (24.0%)
- **Decisive Pairs:** $n = 17 + 12 = 29$.
- Under $H_0: p = 0.50$, the number of won pairs follows $\text{Binomial}(29, 0.50)$:
  $$\text{Two-tailed } p = 2 \times \sum_{k=0}^{12} \binom{29}{k} 0.5^{29} = \mathbf{0.4583}$$

### 4. Rigorous Interpretation for Milestone v0.34

1. **Absence of Proof of Strength Gain:**
   The observed point estimate is positive (+13.9 Elo, 52.0% score, 17 pairs won vs 12 pairs lost), but because true parity ($50.0\%$, $0.0\text{ Elo}$) is well inside all confidence intervals ($p = 0.574$ paired t-test, $p = 0.458$ sign test), the null hypothesis of equal strength cannot be rejected.
2. **Directional Value for Evaluation Design:**
   The candidate achieved 52.0% despite searching $-0.23$ plies shallower ($3.51$ vs $3.74$ plies), confirming the hypothesis that positional evaluation quality offsets shallow depth deficits.
3. **Mandate for v0.34:**
   Do not assume v0.33 evaluation features are universally optimal. Implement tapered evaluation and weight calibration with strict out-of-sample validation to establish whether phase-awareness and tuning provide statistically measurable strength gains.
