## 1. Experimental Methodology

### 1.1 Objective
To determine whether adaptive time management—specifically the utilization of Fischer increment ($W_{\text{inc}} = 0.85$) with an OS safety reserve ($R_{\text{safe}} = 50\text{ ms}$) and dynamic horizon estimation ($N = 30$)—yields a measurable playing-strength advantage over an uncalibrated reference policy ($W_{\text{inc}} = 0.0, R_{\text{safe}} = 0\text{ ms}, N = 40$) under identical evaluation and search heuristics.

### 1.2 Isolation Controls
Both engines ran:
- **Same Binary & Build:** Pure Project Janus runtime (`python -m janus.uci`).
- **Same Evaluation:** Janus v0.34 Tapered Evaluation (`CONFIG_V034_TAPERED`, `--eval-all`).
- **Same Search Features:** PVS, TT (50k entries), LMR, NMP, Killer/History heuristics.
- **Same Opening Book:** Paired openings from `benchmarks/openings.json` with reversed colors.
- **Same Supervision:** Fresh `SupervisedEngineSession` per game, isolated process lifecycles.
- **Time Control:** $3000\text{ ms initial clock} + 100\text{ ms increment per move}$.
