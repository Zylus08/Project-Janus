## 1. Executive Summary & Provenance

Project Janus v0.50 investigated whether moving the performance-critical chess search pipeline into a native C++ module can reproduce the engine's chess behaviour while eliminating the computational overhead of Python-level search orchestration.

In v0.49, fine-grained C FFI calls for move-sorting subroutines failed because marshalling arrays across `ctypes` added more interpreter overhead than C saved (+6.66% runtime regression). Milestone v0.50 solved this boundary bottleneck by implementing a **monolithic native search pipeline (Candidate N2)** in C++17, keeping Python strictly as the orchestration and validation harness.

### Key Empirical Findings

1. **Move Generation Acceleration (~800x faster):**
   - Implemented a 64-bit bitboard board state (`NativeBoard`), precomputed attack tables, ray-cast slider attacks, and inlined bitscan intrinsics.
   - Achieved **15.0 to 16.16 Million NPS** in legal move generation, compared to ~20,000 NPS in `python-chess`.
2. **Exhaustive Correctness Qualification:**
   - **FEN round-trip**: 37/37 (100.0%) bit-exact match against `python-chess`.
   - **Check detection**: 37/37 (100.0%) exact agreement.
   - **Legal move generation**: 37/37 positions (1,135 legal moves) and 1,475 game positions (42,041 moves) verified with **100.0% exact set identity**.
   - **Perft qualification**: All 18 standard Perft test suites (including Kiwipete, Pos 3, 4, 5, 6) passed with **100% exact node counts**.
   - **Make/Unmake transitions**: 178 legal transitions verified with bit-exact board and Zobrist hash restoration.
3. **End-to-End Alpha-Beta Search Speedup (19.4x to 51.3x faster):**
   - Implemented iterative deepening, 1M-entry transposition table, quiescence search, delta pruning, MVV-LVA capture ordering, killer moves, and history heuristic.
   - At Depth 5 on the 37 diagnostic positions, search runtime dropped from **195.99s (Python K0) to 10.12s (Native N2)**, delivering a **19.4x wall-clock speedup** (353,462 NPS vs 6,387 NPS).
4. **Move Agreement Convergence with Depth:**
   - Move agreement between K0 and N2 increased monotonically: 43.2% at Depth 1, 59.5% at Depth 2, 64.9% at Depth 3, 70.3% at Depth 4, and **78.4% at Depth 5**.
   - Residual divergences at Depth 5 were categorized: 75% are quiet-move score symmetries (within 15 cp) resulting from internal move-generation enumeration order.
5. **Tactical Equivalence & Stalemate Superiority:**
   - On the 12-position tactical regression corpus, N2 achieved parity with K0 at Depth 4 (50.0% vs 50.0%) and Depth 5 (41.7% vs 41.7%), running **18.08x to 35.16x faster**.
   - In `tac_11_stalemate_avoidance`, K0 blundered into a stalemate draw (`b6c7`), whereas Native N2 correctly found `b6a6` to maintain a winning advantage.
6. **Fixed-Time Decision Quality Superiority:**
   - Evaluated across all 7 budget tiers (50ms to 3000ms), Native N2 searched **+1.69 to +2.32 plies deeper** than Python K0 at every tier.
   - Native N2 achieved superior agreement with Stockfish 19 reference moves across all 7 budget tiers, outperforming K0 by up to **+13.5 percentage points** (37.8% vs 24.3% at 100ms; 40.5% vs 27.0% at 180ms and 250ms).
7. **Disposition:** **Category B (Native Core Feasible, Further Work Required Before Transition)**. Python K0 remains the immutable production default.

## 4. Native Architecture & Board Representation (Phase C)

Candidate N2 was architected in standard C++17 with strict zero-heap search execution:
- **`NativeBoard`**: Contains `pieces[2][6]` (bitboards per color and piece type), `occupancy[3]` (white, black, all), `side_to_move`, `castling_rights`, `ep_square`, `halfmove_clock`, `fullmove_number`, and `zobrist_key`.
- **`UndoInfo`**: POD struct capturing captured piece, castling rights, ep square, halfmove clock, and previous Zobrist hash.
- **Move Encoding**: Packed 16-bit unsigned integer:
  * Bits 0–5: Source square (0–63).
  * Bits 6–11: Destination square (0–63).
  * Bits 12–15: Special flags (Normal, En Passant, Castle, Knight/Bishop/Rook/Queen Promotion).
- **FFI Contract**: Coarse-grained `extern "C"` boundary passing pointers to caller-allocated POD structs.

## 8. Final Decision & Roadmap for v0.51 (Phases K & L)

### Disposition: Category B — Native Core Feasible, Further Work Required Before Transition

- **Justification**:
  1. Throughput improvement (**19.4x to 51.3x**) vastly exceeds the >5x threshold.
  2. Depth 5 move agreement (**78.4%**) exceeds the >70% requirement but is below the >90% threshold for immediate Category A production replacement.
  3. Tactical parity is established, with zero semantic bugs across 42,041 moves and 18 Perft suites.
  4. Retaining Python K0 as the default production engine while qualifying N2 in v0.51 ensures strict adherence to Janus's scientific governance.

### v0.51 Roadmap
1. **Full UCI Engine in C++**: Move UCI loop directly into native executable to enable tournament play without Python FFI.
2. **Threefold Repetition Tracking**: Implement 1,024-entry game history stack.
3. **Static Exchange Evaluation (SEE)**: Implement native bitboard SEE for capture pruning in quiescence search.
4. **200-Game Head-to-Head Match**: Quantify empirical Elo gain of N2 vs K0 under tournament time controls.
