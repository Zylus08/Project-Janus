## 1. Executive Summary

Project Janus v0.52 investigated whether implementing **Late Move Reductions (LMR)** within the compiled C++17 native search engine improves effective search efficiency and playing strength under controlled Fischer tournament conditions.

In prior milestones, Python-level search optimizations faced increasing orchestration overhead. The v0.51 milestone introduced Native N2, which defeated Python K0 (+478 Elo) by moving the entire search traversal into C++17. In v0.52, we integrated late move reductions directly into this native search architecture.

### Key Milestones Achieved:
1. **Mandatory Tournament Controller Remediation:** Remediated the audit finding from v0.51.1 by completely replacing the artificial 150-ply cutoff with sound FIDE tournament adjudications (threefold repetition, fivefold repetition, 50-move rule, 75-move rule, insufficient material, checkmate, stalemate) plus an emergency 300-ply non-FIDE safety horizon.
2. **C++17 Search Invariant Implementation:** Designed and implemented a 10-guard LMR filter protecting root moves, in-check nodes, checking moves, captures, promotions, and hash moves, combined with full-depth re-searches whenever a reduced move improves $\alpha$.
3. **Rigorous Semantic & Safety Gates:** 20/20 invariant tests passing (`test_native_lmr_semantics.py`). Zero dropped solutions across 28 tactical regression and validation positions.
4. **Algorithmic Search Tree Pruning:** Achieved a **64.56% tree reduction** (2.03x speedup) at Depth 5 and a **63.07% tree reduction** (**3.05x speedup**) at Depth 6 across a 53-position benchmark suite, with re-search rates strictly below 1.5%.
5. **Monotonic Fixed-Time Depth Scaling:** Across 7 time tiers (50ms to 3000ms), N3 consistently completed deeper nominal search trees than N2, reaching **+1.12 plies deeper search** at 2.0s and 3.0s.
6. **Decisive Preregistered Strength Match Victory:** In a 100-pair (200-game) head-to-head match under Fischer 3.0s + 100ms:
   - **Score:** 115.0 / 200 (57.50%, +58 =114 -28)
   - **Estimated Elo Advantage:** **+52.5 Elo** (95% Bootstrap CI: $[+20.9, +85.0]$ Elo)
   - **Paired Student-t Statistic:** $t = 3.2764$, $df = 99$, **$p = 0.00145$** ($p < 0.005$)
   - **Adjudication Integrity:** 100% sound FIDE game terminations (zero 300-ply cutoffs, zero forfeits, zero crashes).

## 2. Invariant & Safety Architecture

A candidate move $m$ searched at nominal depth $d$ is reduced by $R = 1$ ply if and only if all ten criteria are simultaneously satisfied:

```
+----+--------------------------------+--------------------------------------------------------------------+
| #  | Invariant Gate                 | Exact C++ Guard Implementation                                     |
+----+--------------------------------+--------------------------------------------------------------------+
| 1  | Global Feature Activation      | g_use_lmr == true                                                  |
| 2  | Non-Root Node                  | ply > 0                                                            |
| 3  | Minimum Depth Floor            | depth >= g_lmr_min_depth (Default: 3)                              |
| 4  | Move Ordering Rank Floor       | moves_searched >= g_lmr_move_threshold (Default: 4)                |
| 5  | Position Free from Check       | !in_check (Current side to move is not in check)                   |
| 6  | Quiet Move (Non-Capture)       | undo.captured_piece == NO_PIECE (Non-capture & non-EP)             |
| 7  | Non-Promotion Move             | move_flag(m) != 3                                                  |
| 8  | Non-Checking Move              | native_is_check(b) == 0 (Move does not deliver check to opponent)  |
| 9  | Non-Hash Move                  | m != tt_move (Transposition Table move is immune)                  |
| 10 | Toggling Baseline Safety       | UseLMR=false executes bit-identical N2 code path                   |
+----+--------------------------------+--------------------------------------------------------------------+
```

### Full-Depth Re-Search Policy:
```cpp
if (is_lmr_eligible) {
    g_lmr_eligible_moves++;
    int reduction = g_lmr_base_reduction;
    int reduced_depth = std::max(1, child_depth - reduction);
    g_lmr_reduced_moves++;

    score = -negamax(b, reduced_depth, -beta, -alpha, ply + 1, nodes, deadline, aborted, &child_best);

    // Re-search at full nominal depth if reduced move improved alpha
    if (score > alpha && !aborted) {
        g_lmr_researches++;
        score = -negamax(b, child_depth, -beta, -alpha, ply + 1, nodes, deadline, aborted, &child_best);
    }
} else {
    score = -negamax(b, child_depth, -beta, -alpha, ply + 1, nodes, deadline, aborted, &child_best);
}
```
