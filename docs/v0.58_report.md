## 1. Executive Summary

Project Janus v0.58 implements, trains, integrates, and empirically evaluates the first learned chess move-ordering policy model in Project Janus. The experimental candidate, **Janus Neural N8-A**, integrates a supervised deep neural network (`MicroPolicyNet`, 643,200 parameters) directly into the native C++17 alpha-beta search engine, using the frozen **Janus Classical Baseline C1** as the control.

### Major Achievements & Findings

1. **Deterministic 4,168-Dimensional Action Space:**
   Solved the classical promotion ambiguity problem ($64 \times 64 = 4096$ cannot distinguish queen from rook/bishop/knight promotions). Engineered an exact 4,168-action space mapping normal moves and queen promotions to $[0, 4095]$, rook underpromotions to $[4096, 4119]$, bishop underpromotions to $[4120, 4143]$, and knight underpromotions to $[4144, 4167]$. Mathematically proved and verified zero collisions with 100% lossless round-trip decoding.
2. **Supervised Policy Generalization:**
   Trained on 80,000 deduplicated positions extracted across 1,500 grandmaster/master games from the authentic Lichess Elite database ($2400+$ vs $2200+$). The trained `MicroPolicyNet` achieved:
   - **Validation Top-1 Accuracy:** **16.18%** ($7.5\times$ over the 2.15% unigram frequency baseline).
   - **Validation Top-3 Accuracy:** **30.48%** ($6.7\times$ over the 4.55% baseline).
   - **Held-Out Test Set Generalization:** Top-1 = **16.18%**, Top-3 = **30.92%**.
3. **C++17 Native Inference with Selective Action Logits:**
   Implemented the complete forward pass in C++17 without external heavy runtimes. Introduced the **Selective Action Logit Optimization**, which computes Layer 2 logits only for the legal candidate moves generated at the node ($k \approx 30$ moves) rather than evaluating all 4,168 outputs. This reduced Layer 2 multiply-adds from 533,504 to 3,840, reducing forward pass latency from $350\ \mu\text{s}$ down to $< 30\ \mu\text{s}$.
4. **Search Gating & Overhead Minimization:**
   Evaluated three search gating architectures across 16 validation positions at Depths 5 and 6. Selected **N8-A (Root-Only Policy, MaxPly=0, MinDepth=4)**, which strictly caps inference overhead at $< 1.0\ \text{ms}$ per move ($< 1\%$ of time budget), preventing the severe search depth starvation observed in internal node gating (+49.66% time overhead in N8-B).
5. **System Correctness & Full Regression:**
   - 100% bit-exact tensor parity between Python reference and C++ bitboard extraction.
   - Bit-exact search parity with Baseline C1 when `UseNeuralPolicyOrdering=false`.
   - All **644 / 644 unit tests passed cleanly (639 inherited + 5 v0.58)**.
6. **Tactical Safety Parity:**
   In 12 curated tactical benchmark problems, Candidate N8-A achieved **100% move choice parity with Baseline C1 (12/12 identical moves)**, confirming that tactical safeguards (TT moves, promotions, captures, killers) strictly override neural policy scores.
7. **Preregistered 200-Game Tournament:**
   In a preregistered 200-game match over 100 balanced opening pairs under Fischer $3.0\ \text{s} + 100\ \text{ms}$:
   - **Score:** N8-A scored **36 wins, 129 draws, 35 losses** = **100.5 / 200 points (50.25%)**.
   - **Estimated Elo Advantage:** **$+1.7\ \text{Elo}$** (95% Bootstrap CI: $[-26.1, +29.6]$).
   - **Paired Student-t:** $t = +0.1234, p = 0.9020$ ($df = 99$).
   - **Terminations:** 126 threefold repetitions, 71 checkmates, 3 insufficient material, 0 forfeits/crashes.
8. **Release Classification:**
   Formally classified as **Category B — Research Prototype Qualified**. The neural policy ordering mechanism is certified as a stable, robust prototype and retained under the UCI option `UseNeuralPolicyOrdering` (disabled by default to preserve Baseline C1 bit-exact behavior).

### 2.3 The 4,168-Dimensional Action Space
Standard move representations ($64 \times 64 = 4096$) cannot distinguish promotions sharing the same from/to squares. We formulated the **Janus 4,168-Action Space**:
- **Standard Moves & Queen Promotions ($a \in [0, 4095]$):**
  $$a = s_{\text{from}} \times 64 + s_{\text{to}}$$
- **Underpromotions ($a \in [4096, 4167]$):**
  With from-file $f \in [0, 7]$ and direction $f' - f \in \{-1, 0, 1\}$, transition index $t = f \times 3 + (f' - f + 1) \in [0, 23]$:
  - Rook underpromotion: $a = 4096 + t \in [4096, 4119]$
  - Bishop underpromotion: $a = 4120 + t \in [4120, 4143]$
  - Knight underpromotion: $a = 4144 + t \in [4144, 4167]$
- **Collision Count:** Strictly zero collisions across all legal chess moves. Verified 100% lossless round-trip decoding.

## 4. Phase 3: C++ Native Inference Engine Integration

### 4.1 C++ Forward Pass & Selective Action Optimization
```cpp
// Selective Action Logit Optimization (evaluates only generated legal moves)
float hidden[128];
g_policy_model.forward_hidden(tensor, hidden); // Layer 1 (114,688 ops)

float raw_logits[MAX_MOVES];
for (int i = 0; i < n; i++) {
    int a = encode_action_canonical(b, moves[i]);
    raw_logits[i] = g_policy_model.get_logit_for_action(hidden, a); // 128 ops per legal move
}
```
Evaluating only legal candidate moves ($k \approx 30$) reduces Layer 2 multiply-adds from 533,504 to 3,840, reducing forward pass latency from $350\ \mu\text{s}$ down to $< 30\ \mu\text{s}$.

### 4.2 Move Ordering Score Integration
When neural policy ordering is active, quiet moves are scored via masked softmax:
$$\pi(m_i) = \frac{\exp(z_{a_i} - \max_j z_{a_j})}{\sum_{j=1}^n \exp(z_{a_j} - \max_j z_{a_j})}$$
$$\text{NeuralScore}(m_i) = 20,000 + \text{int}(50,000 \times \pi(m_i)) \in [20,000, 70,000]$$

Tactical moves strictly supersede neural quiet scores:
1. TT Best Move: $10,000,000$
2. Promotions: $800,000 - 900,000$
3. Winning Captures: $100,000 + \text{MVV-LVA}$
4. Equal Trades: $95,000 + \text{MVV-LVA}$
5. Primary Killer: $90,000$
6. Secondary Killer: $80,000$
7. Neural Policy Quiets: $[20,000, 70,000]$
8. History Heuristic Quiets: $\le 16,384$
9. Unscored Quiets: $0$

**Strict Invariant:** No move is ever pruned or discarded based on neural policy probability.
